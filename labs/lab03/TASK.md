# ЛР3. Два источника курса

Вариант: **FX**.

## Что дано

Предметные объекты, внешний API и вспомогательные типы уже подготовлены. В `app/domain/providers.py` даны заготовки общего интерфейса и двух исполнителей. Их поведение и основной метод `FxService.convert()` требуется завершить самостоятельно. Сигнатуры сохранены; новые слои и выбор архитектуры не нужны.

## Задание

### Шаг 1. Реализуйте общий интерфейс и два поведения

Оформите `ExchangeRateProvider` как абстрактный класс. `TableRateProvider` должен искать точную упорядоченную пару. `FixedRateProvider` обслуживает только пару своего `ExchangeRate`, а не любые валюты.

Если пара не поддерживается, вызывайте `RATE_NOT_FOUND`. Сервис должен работать через `get_rate()`, не проверяя конкретный тип источника.

### Шаг 2. Соберите путь вызова в `FxService.convert()`

Проверьте целевую валюту. При совпадении валют верните исходную сумму без поиска. Иначе получите курс, проверьте тип и направление пары (`INVALID_RATE_PAIR`), затем умножьте и округлите только денежный результат. Не выбирайте алгоритм по конкретному классу исполнителя.

### Шаг 3. Проверьте повторное использование

Один источник многократно обслуживает прямую пару; ошибка отсутствующей пары не меняет сохранённый курс. Неверная целевая валюта не меняет исходную сумму.

## Примеры и границы

- Табличный курс USD/EUR = `0.85` переводит `100` в `85`; фиксированный `0.80` — в `80`.
- Фиксированный источник USD/EUR не обслуживает EUR/USD и вызывает `RATE_NOT_FOUND`.
- Перевод без смены валюты не вызывает ни один источник.
- Оба источника возвращают `ExchangeRate`.

Последовательности и конфигурации дополнительно проверяются в `tests/test_progression.py`. Прочитайте ожидаемый результат каждого сценария до реализации.

Все проверки открыты: `tests/test_contract.py` и `tests/test_review_contract.py`.

## Дополнительное задание

**Запасной локальный источник.** Добавьте `FallbackRateProvider(primary, fallback)` — наследник `ExchangeRateProvider`. Сначала `get_rate(source, target)` вызывает `primary`. Только `DomainError("RATE_NOT_FOUND")` разрешает один вызов `fallback`; остальные ошибки передаются вызывающему коду.

Оба источника должны вернуть `ExchangeRate` нужного направления, иначе вызывается `INVALID_RATE_PAIR` без дополнительного поиска. Переданные объекты сохраняются без копирования. `FxService` и стандартную сборку не меняйте: правило проверяется напрямую, без сети, кэша и обратных курсов.

Проверка: `python check.py lab03 --bonus`.
