# FX: справка по объектам

Здесь описаны данные и методы сервиса. Нужные изменения для ЛР1 перечислены в [TASK.md](TASK.md).
Часть методов уже реализована в заготовке, остальные добавляются по мере выполнения работ.

## Данные и поведение

`FxService` переводит сумму в другую валюту по заданному учебному курсу. Внешние источники курсов не используются.

| Объект или метод | Назначение |
|---|---|
| `Money` | Готовая неотрицательная сумма `Decimal` в EUR или USD. |
| `ExchangeRate(source, target, rate)` | Курс: количество единиц `target` за одну единицу `source`. Валюты различаются, курс положителен и конечен. |
| `ExchangeRateProvider.get_rate(source, target) -> ExchangeRate` | Общий интерфейс получения курса. |
| `TableRateProvider(rates)` | Ищет точную пару в локальной таблице. |
| `FixedRateProvider(exchange_rate)` | Обслуживает только пару переданного курса. |

`FxService.convert(money, target_currency) -> Money` умножает сумму на курс и один раз округляет результат до `0.01` по правилу `HALF_UP`. Нулевая сумма допустима. При одинаковых валютах метод возвращает равное значение без вызова источника.

Источник должен вернуть курс запрошенного направления, иначе вызывается `INVALID_RATE_PAIR`. Отсутствующий курс — `RATE_NOT_FOUND`. Входные данные не меняются.

`Money`, проверка валюты, локальный контекст `Decimal` с точностью `28` и денежное округление уже подготовлены. Сам курс может иметь больше двух знаков после запятой.

## Работа с готовым кодом

Обращение к сервису выполняется через `app/api.py`. Разрешённые файлы указаны в [TASK.md](TASK.md).
Проверки используют подготовленные данные и не зависят от работы других групп.

Функции `create`, `make`, `call` и `view` связывают готовый API с реализацией. Используемые ими функции сервисного модуля должны сохранять сигнатуры. Сам `app/api.py` не редактируйте.

До ЛР5 сборка предоставлена готовой. Нужные объекты могут создаваться в сервисном модуле; `assembly.py` менять не нужно.

Сборка принимает `rates`, а начиная с ЛР3 — также `provider`. В ЛР6 для стандартной таблицы включён обратный поиск.

## Ошибки и результаты

`DomainError` содержит код ошибки. При отказе проверки состояние объекта не должно меняться.
Ошибка переданной зависимости не заменяется успешным результатом. Конкретные коды и примеры
приведены в задании и открытых тестах.
